Pedidos que disparam a skill:

> "Inicia um frontend novo para esse projeto com o stack do portal."

> "Faz o bootstrap: Vite, PrimeVue unstyled, Tailwind 4, Pinia."

```text
você:  cria o frontend do sistema de frota, com login e um dashboard vazio
claude: (carrega frontend-kickstart) → scaffolding com a arquitetura em
        camadas, tokens.css copiado, axios + interceptors, layout shell…
```

Use para **começar do zero**. Para trabalhar num app que já segue o padrão, a skill certa
é a [`portal-frontend`](./portal-frontend).
